# Advanced Local RAG Backend (FastAPI + LangChain + Ollama + Hybrid Search + BGE Reranker)

Автономный бэкенд-сервис для работы с локальной RAG-системой (**Retrieval-Augmented Generation**). Сервис выстраивает интеллектуальный поиск и генерацию ответов по документам (`.pdf`, `.txt`, `.docx`), используя гибридный поиск и переранжирование через нейронные сети.
Разработанно совместнно с [@Vano1i]

---

##  Архитектурные особенности

1. **Двухуровневая разбивка контекста (Contextual Chunking)**:
   - Документы разбиваются на крупные родительские блоки (Parent: 2000 символов) и мелкие дочерние фрагменты (Child: 400 символов).
   - В метаданных дочерних блоков сохраняется контекст родительского слоя, что обеспечивает высокую точность при генерации ответа LLM.

2. **Гибридный поиск (Hybrid Search)**:
   - **Векторный ретривер**: Хранилище ChromaDB с локальными векторными эмбеддингами `nomic-embed-text` от Ollama.
   - **Полнотекстовый ретривер**: `BM25Retriever` (алгоритм BM25) для поиска точных совпадений ключевых терминов и наименований.
   - Результаты объединяются через `EnsembleRetriever`.

3. **Нейросетевое переранжирование (Cross-Encoder Reranking)**:
   - Для окончательной сортировки найденных фрагментов используется модель `BAAI/bge-reranker-base`. Она точно оценивает релевантность текста запросу и выбирает Top-N наиболее подходящих отрывков.

4. **Полная автономность и оффлайн-режим**:
   - Приложение работает 100% локально на сервере/компьютере пользователя. Данные не передаются во внешние облачные сервисы.

5. **Потоковый ответ (Streaming API)**:
   - Поддержка Server-Sent Events (SSE) в эндпоинте `/api/chat/stream` для посимвольного вывода ответа в реальном времени.

##  Запуск и установка

### 1. Требования
- Python 3.9+
- Запущенный сервис [Ollama](https://ollama.com/)

Скачайте требуемые локальные модели в Ollama:
```bash
ollama pull llama3:8b
ollama pull nomic-embed-text
```

### 2. Настройка окружения
```bash
python -m venv .venv

# Активация окружения (Windows):
.venv\Scripts\activate

# Активация окружения (Linux/macOS):
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Файл конфигурации
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

### 4. Запуск сервера
```bash
uvicorn main:app --reload --port 8000
```
Сервер будет доступен по адресу: `http://127.0.0.1:8000`.

##  Основные эндпоинты API

- `POST /api/chat/stream` — Стриминговая генерация ответа с реранкингом и источниками.
- `POST /api/chat` — Синхронный ответ на вопрос.
- `GET /api/docs` — Список проиндексированных файлов.
- `POST /api/reload-docs` — Динамическая переиндексация базы знаний.
- `GET /api/docs/{filename}` — Скачивание оригинала документа.
- `GET /api/sessions` — Список диалогов.
